Build a complete, fully functional web application called:

STEGOCRYPT
Secure Text & Image Communication using AES + LSB Steganography

IMPORTANT:
This must be a REAL WORKING WEB APPLICATION, not a static UI prototype.

Do NOT require Java, JDK, NetBeans, Eclipse, IntelliJ, a Java backend, or any external Java implementation.

Reimplement the complete functionality of the original Java-based StegoCrypt concept using browser-compatible JavaScript/TypeScript so that everything works directly in the website.

PROJECT OBJECTIVE

The application demonstrates hybrid secure communication by combining:

1. AES encryption for confidentiality
2. LSB image steganography for hiding encrypted data
3. Extraction of hidden encrypted data
4. AES decryption for recovering the original message

The complete flow must work inside the browser.

CORE WORKFLOW

SENDER:

User enters:
- Secret message
- AES password/key
- Cover image

Then:

Plaintext
   ↓

   ↓

   ↓

   ↓

Download/share stego image

RECEIVER:

User uploads:
- Stego image
- AES password/key

Then:

Stego Image
   ↓
LSB Extraction
   ↓
Encrypted ciphertext
   ↓
AES Decryption
   ↓
Original plaintext

The sender and receiver workflows must be connected and actually interoperable.

--------------------------------------------------
AES ENCRYPTION
--------------------------------------------------

When user clicks:

"Encrypt & Embed"

Perform these actual operations:

1. Generate random salt.
2. Derive AES key from password using PBKDF2.
3. Generate random IV/nonce.
4. Encrypt plaintext using AES-GCM.
5. Convert encrypted result into a binary payload.
6. Add a small structured payload header containing:
   - Magic identifier: STEGOCRYPT
   - Version
   - Algorithm identifier
   - Salt
   - IV
   - Ciphertext length
7. Convert complete payload into bits.
8. Embed bits into image pixels using LSB.

Do not merely simulate these operations.

The generated stego image must contain the actual encrypted payload.

--------------------------------------------------
LSB STEGANOGRAPHY
--------------------------------------------------

Implement real LSB image embedding using Canvas ImageData.

For each pixel:

Read RGB/RGBA values.

Modify the least significant bit of pixel channels.

Prefer using RGB channels and preserve alpha.

For example:

R → R with modified LSB
G → G with modified LSB
B → B with modified LSB

Do not unnecessarily modify alpha.

Create a deterministic bit sequence from the payload.

The extraction algorithm must reverse the exact embedding process.

IMPORTANT:

The application must be able to:

Encode message → download stego image → refresh website → upload stego image → enter password → successfully recover the original message.

This must work independently of application state.

PSNR / IMAGE QUALITY
--------------------------------------------------

Implement actual image quality analysis.

Calculate:

MSE
PSNR

Formula:

MSE = average squared pixel difference

PSNR = 10 × log10(MAX² / MSE)

For RGB images use the RGB pixel differences.

Display:

MSE:
0.00...

PSNR:
XX.XX dB

Interpretation:

Higher PSNR = lower visible distortion.

Use the project's target concept of maintaining high visual quality.

Do not falsely claim a guaranteed PSNR value.

Calculate the actual value for the uploaded image.
